# `database` module

PostgreSQL 16 on RDS for every Euron Open TestForge table: organizations, users and API keys, projects, source imports and their analysis, generated tests, test runs with results and coverage, pull requests, webhooks, usage, the append-only audit log, and the job queue itself (claimed with `FOR UPDATE SKIP LOCKED` under a lease, so the worker and the scheduler need nothing but Postgres to share work). Uploaded ZIPs, source snapshots and reports live in S3; rows keep only the object key.

- Private subnets, no public access, ingress added per consumer security group (the api, worker, scheduler and migrate tasks; never the sandbox).
- Encrypted with the CMK, TLS enforced (`rds.force_ssl`), IAM auth, Performance Insights, enhanced monitoring, PostgreSQL logs to CloudWatch, `idle_in_transaction_session_timeout` so a crashed task never holds a claimed job's row lock for long.
- The master password is generated, and folded into `DATABASE_URL` for the secrets module (Secrets Manager), never into plain task environment.

## Inputs

| Name | Description | Type | Default |
|---|---|---|---|
| `name_prefix` | Prefix for every resource name. | `string` | required |
| `vpc_id` | VPC id. | `string` | required |
| `subnet_ids` | Private subnets for the DB subnet group (2+ AZs). | `list(string)` | required |
| `kms_key_arn` | CMK for storage and Performance Insights. | `string` | required |
| `database_name` | Initial database name. | `string` | `"testforge"` |
| `master_username` | Master user name. The password is generated by Terraform and only ever stored inside DATABASE_URL in Secrets Manager. | `string` | `"testforge_admin"` |
| `engine_version` | PostgreSQL major (or major.minor) version. | `string` | `"16"` |
| `instance_class` | Instance class. Graviton (t4g/m7g/r7g) recommended. | `string` | `"db.t4g.medium"` |
| `allocated_storage` | Initial gp3 storage in GiB. | `number` | `50` |
| `max_allocated_storage` | Storage autoscaling ceiling in GiB. Run results and coverage grow with every run until retention purges them, so leave headroom. | `number` | `500` |
| `multi_az` | Synchronous standby in a second AZ. | `bool` | `false` |
| `backup_retention_days` | Automated backup retention. | `number` | `7` |
| `deletion_protection` | Block accidental deletion. | `bool` | `true` |
| `monitoring_interval` | Enhanced Monitoring granularity in seconds (0 disables): 1, 5, 10, 15, 30 or 60. | `number` | `60` |
| `skip_final_snapshot` | Skip the final snapshot on destroy (throwaway envs only). | `bool` | `false` |

## Outputs

| Name | Description |
|---|---|
| `address` | DB hostname. |
| `port` | DB port. |
| `database_name` | Database name. |
| `instance_identifier` | RDS instance identifier (CloudWatch dimension). |
| `security_group_id` | DB security group; consumers add ingress rules against it. |
| `master_username` | Master username. |
| `connection_url` | DATABASE_URL for the api, worker, scheduler and migrate (SQLAlchemy asyncpg dialect, TLS required). Pass it to the secrets module, never to plain task environment. |
